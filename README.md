# JARVIS Neural Core — PWA (Android)

Versão do HUD do JARVIS adaptada para Android, fiel ao visual original (cores ciano/laranja, status, núcleo neural avançado).

## Como usar

1. Suba **todos os arquivos** desta pasta para a **raiz** do seu repositório GitHub.
2. Ative **GitHub Pages** (Settings → Pages → Source: main / root).
3. Pegue o link da Pages.
4. Entre em https://www.pwabuilder.com → cole o link → Generate → Android → baixe o APK.

## Arquivos

- `index.html` — App completo
- `manifest.json` — Manifesto PWA
- `sw.js` — Service Worker
- `icons/` — Ícones 192 e 512

Pronto para PWABuilder gerar o APK.
